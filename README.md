## How I approach software engineering

- **Maintainability first:** favour clear, understandable code and incremental improvements.
- **Quality built in:** use testing, refactoring, and review to reduce regressions.
- **Pragmatic architecture:** choose designs that fit the problem and can evolve with it.
- **End-to-end ownership:** consider implementation, QA, release, and ongoing support—not just writing code.
- **Collaborative delivery:** help clarify requirements, triage issues, and prioritise technical work.
